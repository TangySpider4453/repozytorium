Czasowniki nieregularne 1–23

Niemiecki, kartkówka śr. 28 października. Podręcznik s. 130: Infinitiv, Partizip Perfekt, znaczenie

Kartkówka 28 października: podręcznik s. 130, czasowniki 1–23. Uczysz się bezokolicznika, Partizip Perfekt (z haben/sein) i znaczenia. Präteritum nie obowiązuje.

Jeśli zapamiętasz tylko tyle

  1. Zwykle: ge- + zmieniony rdzeń + -en: binden → gebunden, bitten → gebeten, brechen → gebrochen.
  2. Przedrostek be-, emp-, er- → bez ge-: begonnen, empfohlen, erschrocken (empfangen = empfangen).
  3. Z sein: bleiben, erschrecken, fahren (jechać), biegen (skręcać). Reszta z haben.

1. ge- … -en

  1. a zostaje: backen → gebacken, braten → gebraten, fahren → gefahren
  2. ie → o: biegen → gebogen, bieten → geboten; e → o: brechen → gebrochen
  3. i → u: binden → gebunden; i → e: bitten → gebeten; ei → ie: bleiben → geblieben
  4. ei → i: beißen → gebissen (po krótkim i piszemy ss)
  5. essen → gegessen – dodatkowe g w środku!

2. bez ge- (be-, emp-, er-)

  1. befehlen → befohlen, empfehlen → empfohlen (e → o)
  2. beginnen → begonnen (i → o)
  3. besitzen → besessen (i → e)
  4. betrügen → betrogen (ü → o)
  5. empfinden → empfunden (i → u), empfangen → empfangen (bez zmian)
  6. erschrecken → ist erschrocken (przestraszyć się)

3. mieszane: ge- … -t

  1. brennen → gebrannt (palić się)
  2. bringen → gebracht (przynosić)
  3. denken → gedacht (myśleć)
  4. dürfen → gedurft (móc)
  5. Końcówka -t jak w regularnych, ale rdzeń się zmienia.

Uważaj na pary

  1. bitten (prosić) → gebeten ≠ bieten (oferować) → geboten
  2. brechen (łamać) → gebrochen ≠ bringen (przynosić) → gebracht
  3. fahren: ich bin nach Berlin gefahren (jechałem), ich habe sie gefahren (wiozłem ją)
  4. biegen: das Auto ist um die Ecke gebogen (skręciło), er hat das Rohr gebogen (wygiął)

Zasłoń kolumnę i odpowiadaj z pamięci. Dotknięcie zasłoniętej komórki ją odsłania. „ist” = Perfekt z sein, „hat” = z haben.
