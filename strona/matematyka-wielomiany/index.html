Wielomian i działania

stopień, współczynniki, wartość, równość, dodawanie i mnożenie

Co to jest wielomian

Wielomian jednej zmiennej x to suma jednomianów postaci a·xⁿ, gdzie n jest liczbą naturalną (0, 1, 2, …):

W(x) = aₙxⁿ + aₙ₋₁xⁿ⁻¹ + … + a₁x + a₀,   aₙ ≠ 0aₙ, …, a₀ to współczynniki
stopień
najwyższa potęga x z niezerowym współczynnikiem; W(x) = 2x³ − 3x² + x − 5 ma stopień 3
współczynnik przy najwyższej potędze
aₙ, tutaj 2
wyraz wolny
a₀, tutaj −5; zawsze W(0) = a₀
wielomian stały
np. W(x) = 7, stopień 0; wielomian zerowy W(x) = 0 nie ma stopnia
Uważaj: wyrażenia z x w mianowniku (np. 1/x) albo pod pierwiastkiem (√x) nie są wielomianami. Za to √2·x + 1 jest wielomianem, bo pierwiastek dotyczy liczby, a nie x.

Wartość wielomianu

Żeby obliczyć W(a), wstawiamy a w miejsce x.

Przykład. W(x) = 2x³ − 3x² + x − 5. W(2) = 2·8 − 3·4 + 2 − 5 = 16 − 12 + 2 − 5 = 1. W(−1) = 2·(−1) − 3·1 + (−1) − 5 = −11.

Przydatne skróty: W(1) = suma wszystkich współczynników, W(0) = wyraz wolny.

Uważaj na znaki przy liczbach ujemnych: (−1)³ = −1, ale (−1)² = +1. Zawsze bierz liczbę ujemną w nawias.

Równość wielomianów

Dwa wielomiany są równe, gdy mają ten sam stopień i równe współczynniki przy tych samych potęgach.

Przykład. W(x) = (a + 1)x² + 3x + b i V(x) = 4x² + 3x − 2. Porównujemy: a + 1 = 4 i b = −2, więc a = 3, b = −2.

Dodawanie, odejmowanie, mnożenie

  • Dodawanie i odejmowanie: dodajemy wyrazy podobne (te same potęgi). Stopień sumy jest co najwyżej równy większemu ze stopni (może spaść, gdy najwyższe wyrazy się skrócą).
  • Mnożenie: każdy wyraz przez każdy, potem redukcja wyrazów podobnych. Stopień iloczynu = suma stopni.
Przykład. P(x) = x³ + 2x² − 1, Q(x) = −x³ + x + 4.
P + Q = 2x² + x + 3 (stopień 2, bo x³ się skróciło).
P − Q = x³ + 2x² − 1 + x³ − x − 4 = 2x³ + 2x² − x − 5.
(x² − 3)(2x + 1) = 2x³ + x² − 6x − 3.
Uważaj: przy odejmowaniu weź cały odejmowany wielomian w nawias i zmień znak każdego wyrazu. Najczęstszy błąd: zmiana znaku tylko pierwszego wyrazu.
Temat 2

Dzielenie wielomianów

dzielenie pisemne, schemat Hornera, twierdzenie o reszcie, twierdzenie Bézouta

Dzielenie z resztą

W(x) = P(x) · Q(x) + R(x)W – dzielna, P – dzielnik, Q – iloraz, R – reszta; stopień R < stopień P
  • Stopień ilorazu = stopień dzielnej − stopień dzielnika (np. 5 − 2 = 3).
  • Przy dzieleniu przez dwumian (x − a) reszta jest liczbą; przez wielomian stopnia 2 reszta ma stopień co najwyżej 1 (postać ax + b).
  • Gdy R(x) = 0, mówimy, że W jest podzielny przez P.

Dzielenie pisemne

Jak dzielenie liczb „pod kreską”: dzielimy najwyższy wyraz dzielnej przez najwyższy wyraz dzielnika, mnożymy, odejmujemy, powtarzamy.

Przykład. (x³ + 2x² − x + 3) : (x² + 1)
1) x³ : x² = x; x·(x² + 1) = x³ + x; odejmujemy: 2x² − 2x + 3
2) 2x² : x² = 2; 2·(x² + 1) = 2x² + 2; odejmujemy: −2x + 1
Stopień −2x + 1 jest mniejszy niż dzielnika, koniec. Iloraz x + 2, reszta −2x + 1.
Uważaj: jeśli w dzielnej brakuje jakiejś potęgi, wpisz ją z zerem (np. x³ + 0x² − 2x + 5). Inaczej kolumny się rozjadą.

Schemat Hornera (dzielenie przez x − a)

Szybki sposób dzielenia przez dwumian x − a. W pierwszym wierszu wpisujemy współczynniki dzielnej (wszystkie, także zera), z lewej liczbę a. Pierwszy współczynnik przepisujemy, a każdy następny: poprzedni wynik · a + współczynnik z góry.

Przykład. (2x³ − 3x² + 4x − 5) : (x − 2), więc a = 2.
2−34−5
a = 222·2 − 3 = 11·2 + 4 = 66·2 − 5 = 7

Ostatnia liczba to reszta = 7, pozostałe to współczynniki ilorazu (o stopień niższego): 2x² + x + 6.

Uważaj: przy dzieleniu przez (x + 4) wpisujesz a = −4, bo x + 4 = x − (−4). Horner działa tylko dla dzielnika postaci x − a.

Twierdzenie o reszcie

reszta z dzielenia W(x) przez (x − a) = W(a)nie trzeba dzielić, wystarczy obliczyć wartość
Przykład. Reszta z dzielenia 2x³ − 3x² + 4x − 5 przez (x − 2) to W(2) = 16 − 12 + 8 − 5 = 7. Zgadza się z Hornerem.

Twierdzenie Bézouta

W(a) = 0  ⇔  W(x) jest podzielny przez (x − a)a jest pierwiastkiem wtedy i tylko wtedy, gdy (x − a) dzieli wielomian
Przykład. Dla jakiego m wielomian x³ + mx² + 5x − 6 jest podzielny przez (x − 2)? Z Bézouta W(2) = 0: 8 + 4m + 10 − 6 = 0, czyli 4m + 12 = 0, m = −3.
Temat 3

Rozkład na czynniki i pierwiastki

wyłączanie, grupowanie, wzory skróconego mnożenia, pierwiastki wymierne, krotność

Pierwiastek wielomianu

Liczba a jest pierwiastkiem wielomianu W, gdy W(a) = 0. Wielomian stopnia n ma co najwyżej n pierwiastków rzeczywistych.

Metody rozkładu

1. Wyłączanie przed nawias

x³ − 4x = x(x² − 4) = x(x − 2)(x + 2)

2. Grupowanie

x³ + 2x² − 9x − 18 = x²(x + 2) − 9(x + 2) = (x + 2)(x² − 9) = (x + 2)(x − 3)(x + 3)

3. Wzory skróconego mnożenia

x³ − 8 = (x − 2)(x² + 2x + 4)
8x³ − 1 = (2x − 1)(4x² + 2x + 1)

4. Podstawienie t = x²

x⁴ − 5x² + 4 = (x² − 1)(x² − 4) = (x − 1)(x + 1)(x − 2)(x + 2)

Wzory skróconego mnożenia (trzeci stopień)

WzórPrzykład
a³ − b³ = (a − b)(a² + ab + b²)x³ − 8 = (x − 2)(x² + 2x + 4)
a³ + b³ = (a + b)(a² − ab + b²)x³ + 27 = (x + 3)(x² − 3x + 9)
(a + b)³ = a³ + 3a²b + 3ab² + b³(x + 1)³ = x³ + 3x² + 3x + 1
(a − b)³ = a³ − 3a²b + 3ab² − b³(x − 2)³ = x³ − 6x² + 12x − 8

Trójmiany z wzorów na sumę i różnicę sześcianów (np. x² + 2x + 4) mają Δ < 0, więc dalej się nie rozkładają.

Szukanie pierwiastków wymiernych

Gdy wielomian ma współczynniki całkowite:

  • Pierwiastki całkowite są dzielnikami wyrazu wolnego a₀.
  • Pierwiastki wymierne p/q (ułamek nieskracalny): p dzieli wyraz wolny, q dzieli współczynnik przy najwyższej potędze.
Przykład. W(x) = 2x³ − x² − 7x + 6. Kandydaci: p ∈ {±1, ±2, ±3, ±6}, q ∈ {1, 2}, czyli ±1, ±2, ±3, ±6, ±1/2, ±3/2.
Sprawdzamy: W(1) = 2 − 1 − 7 + 6 = 0, więc 1 jest pierwiastkiem.
Horner przez (x − 1): współczynniki 2, 1, −6, reszta 0 → W(x) = (x − 1)(2x² + x − 6).
Δ = 1 + 48 = 49, x = (−1 ± 7)/4, czyli 3/2 i −2. W(x) = (x − 1)(2x − 3)(x + 2).

Krotność pierwiastka

Jeśli W(x) = (x − a)ᵏ · Q(x) i Q(a) ≠ 0, to a jest pierwiastkiem k-krotnym.

Przykład. W(x) = (x − 1)²(x + 3)³: 1 jest pierwiastkiem dwukrotnym, −3 trzykrotnym. Stopień W to 2 + 3 = 5.
Uważaj: twierdzenie o pierwiastkach wymiernych daje tylko kandydatów, każdego trzeba sprawdzić. x² + 4 nie rozkłada się na czynniki liniowe (to nie jest wzór skróconego mnożenia!). x³ − 8 ma tylko jeden pierwiastek rzeczywisty, 2.
Temat 4

Równania i nierówności wielomianowe

rozkład na czynniki, iloczyn równy zero, „wężyk”

Równania: schemat

  1. Przenieś wszystko na jedną stronę: W(x) = 0.
  2. Rozłóż W na czynniki (wyłączanie, grupowanie, wzory, Horner z pierwiastkiem wymiernym).
  3. Iloczyn jest zerem, gdy któryś czynnik jest zerem. Przyrównaj każdy czynnik do 0.
  4. Zapisz wszystkie rozwiązania.
Przykład 1. x³ − 2x² − 5x + 6 = 0. W(1) = 1 − 2 − 5 + 6 = 0. Horner: (x − 1)(x² − x − 6) = (x − 1)(x − 3)(x + 2). x ∈ {−2, 1, 3}.
Przykład 2 (dwukwadratowe). x⁴ − 5x² + 4 = 0. t = x² ≥ 0: t² − 5t + 4 = 0, t = 1 lub t = 4. x² = 1 lub x² = 4. x ∈ {−2, −1, 1, 2}.
Przykład 3. x³ + x² − x − 1 = 0. x²(x + 1) − (x + 1) = (x + 1)(x² − 1) = (x + 1)²(x − 1). x ∈ {−1, 1}, −1 jest pierwiastkiem dwukrotnym.
Uważaj: nie dziel obu stron przez x ani przez nawias z x. Z x³ = 4x po podzieleniu przez x gubisz rozwiązanie x = 0. Zamiast tego: x³ − 4x = 0, x(x − 2)(x + 2) = 0, x ∈ {−2, 0, 2}.

Nierówności: metoda „wężyka”

Ta część może wykraczać poza zakres sprawdzianu. Zapytaj nauczyciela, czy będzie.

  1. Rozłóż wielomian na czynniki i znajdź pierwiastki.
  2. Zaznacz pierwiastki na osi liczbowej.
  3. Rysuj wykres od prawej strony: z góry, gdy współczynnik przy najwyższej potędze jest dodatni, z dołu, gdy ujemny.
  4. Przy pierwiastku nieparzystej krotności linia przecina oś, przy parzystej (np. dwukrotnym) się od niej odbija.
  5. Odczytaj przedziały nad osią (W > 0) albo pod osią (W < 0). Przy ≥ i ≤ dołącz pierwiastki.
Przykład. (x − 1)(x + 2)(x − 3) > 0. Pierwiastki −2, 1, 3, współczynnik przy x³ dodatni, więc start z góry po prawej. Znaki od prawej: +, −, +, −. x ∈ (−2; 1) ∪ (3; +∞).
Przykład z pierwiastkiem podwójnym. (x − 2)²(x + 1) ≤ 0. Przy 2 wykres się odbija (zostaje nad osią), przy −1 przecina oś. x ∈ (−∞; −1] ∪ {2}. Nie zapomnij o samym punkcie 2, bo tam W = 0.

Najważniejsze wzory i twierdzenia w jednym miejscu. Zasłoń prawą kolumnę i sprawdź, czy pamiętasz, co oznaczają.

st(P·Q) = st P + st Q

Stopień iloczynu to suma stopni.

W(0) = a₀,  W(1) = suma wsp.

Wyraz wolny i suma współczynników.

W = P·Q + R

Dzielenie z resztą, stopień R < stopień P.

R = W(a)

Twierdzenie o reszcie: reszta z dzielenia przez (x − a).

W(a) = 0 ⇔ (x − a) | W

Twierdzenie Bézouta.

a³ − b³ = (a − b)(a² + ab + b²)

Różnica sześcianów.

a³ + b³ = (a + b)(a² − ab + b²)

Suma sześcianów.

(a ± b)³ = a³ ± 3a²b + 3ab² ± b³

Sześcian sumy i różnicy.

a² − b² = (a − b)(a + b)

Różnica kwadratów (przyda się na koniec rozkładu).

p | a₀,  q | aₙ

Pierwiastek wymierny p/q wielomianu o współczynnikach całkowitych.

Δ = b² − 4ac

Trójmian ax² + bx + c: x = (−b ± √Δ)/(2a). Δ < 0, brak pierwiastków.

A·B = 0 ⇔ A = 0 lub B = 0
